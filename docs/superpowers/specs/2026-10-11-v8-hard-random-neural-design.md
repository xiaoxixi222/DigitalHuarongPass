# 第八代困难随机盘面纯神经增强设计

## 目标

提高“第八代数字华容道高速王”在均匀随机可解盘面上的统计成功率，同时保持运行时纯神经网络：部署阶段只使用已训练模型、合法动作规则和状态去重，不调用 A*、`heuristic_score` 或其他手工路线求解器。

## 方案

训练集由两部分组成：从目标状态反向随机游走得到的轨迹状态，以及直接均匀打乱后筛选出的可解随机盘面。两类状态都使用离线加权 A* 生成监督标签，但按状态去重后再做五折交叉验证。每折采用 D4 对称增强，并在初始模型运行均匀随机盘面后收集 DAgger 状态，重新标注并训练。

运行时 Beam 对每个候选分支使用策略概率、归一化 Q 值、预测剩余距离、风险和路径多样性评分。每轮保留多个不同首动作的候选，避免所有 beam 分支被同一个错误动作占满。失败后继续使用 episode 访问记忆防止反向震荡，但不引入手工距离。

## 验收标准

- checkpoint 仍命名为 `models/第八代数字华容道高速王.pt`，且内嵌全部折模型。
- `load_agent(..., use_guard=False)` 的第八代路径在测试中调用 A* 或 `heuristic_score` 会立即失败。
- 报告同时包含随机游走评估和均匀随机盘面评估，每项都有解出率、30 秒解出率、非法动作率、重复状态数和 beam 失败率。
- 全量测试通过；训练生成训练指标 PNG、早期/最终对比 MP4 和单文件 checkpoint。
