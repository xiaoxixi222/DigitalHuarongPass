# 第八代数字华容道高速王设计规格

**日期：** 2026-10-11  
**状态：** 待用户审阅  
**目标：** 通过交叉验证训练，把离线 A* 教师的解题能力蒸馏到纯神经网络中，使 4×4 数字华容道在不同复杂度盘面上尽量快速完成，并以 30 秒作为运行时硬预算。

## 1. 目标与边界

第八代模型的展示名称固定为 **“第八代数字华容道高速王”**。训练阶段允许使用现有 A* 和更强的离线教师工具生成标签；部署阶段不调用 A*、不调用搜索器，也不使用启发式分数选择动作。运行时只保留神经网络、合法动作过滤、神经 beam 规划和循环检测。

本版本覆盖 4×4 棋盘的可解状态分布，训练数据按真实解距离分层，包含随机游走状态和均匀随机可解状态。由于可解状态空间约为 10.46 万亿，系统不宣称对每个排列提供数学必解证明；验收使用分层测试集和独立随机测试集报告覆盖率、步数、循环率和 30 秒成功率。

30 秒从新盘面开始计时，包含首次神经规划、每步神经决策和固定动画执行时间。超过 30 秒或 100 步即失败并记录样本。部署配置默认沿用当前 300ms 的单步动画节奏，因此 80 步路线约需 24 秒，为首次规划和少量波动留下预算。

## 2. 训练架构

模型采用状态编码器、策略头、剩余距离头、动作价值头和失败风险头：

- 状态编码器接收 16 个棋子 token、棋盘位置编码、空格位置和基础棋盘特征。
- 策略头输出四个方向的 logits。
- 距离头预测当前状态到目标的剩余步数，训练目标为离散距离分桶和连续值联合监督。
- 价值头预测每个合法动作的未来路线质量，用于神经 beam 的节点排序。
- 风险头预测动作后是否可能进入循环、超步数或低置信区域。
- 所有输出都由同一个模型产生，部署时不加载教师模型。

为了控制改动范围，保留 `forward(features) -> (policy_logits, q_values)` 作为旧训练代码的兼容入口；第八代新增 `forward_full(features)`，返回策略、价值、距离和风险输出。第八代训练和运行时统一使用完整接口，并同步升级 checkpoint 版本和加载校验，旧版本 checkpoint 不直接冒充第八代模型。

## 3. 数据集与教师标签

训练样本由完整教师轨迹展开得到，每个样本至少包含：

```text
(state, legal_actions, expert_action, remaining_steps, next_state,
action_rank_targets, failure_risk_target, distance_bucket)
```

教师数据分为四个来源：

1. 目标状态反向随机游走，覆盖距离 0–20。
2. 中深层随机游走，覆盖距离 21–60。
3. 高难随机游走和完全随机可解盘面，覆盖距离 61–80 及模型常见失误状态。
4. DAgger 回合：用当前模型执行，收集它实际访问的状态，再由离线教师为这些状态重新标注。

每个交叉验证折必须按状态去重；同一状态不能同时出现在训练集和验证集。验证集按距离桶、空格位置和首动作类别分层，避免只测浅层盘面。旋转和镜像增强在划分之后进行，保证增强样本不会泄漏到另一折。

## 4. 损失函数与交叉验证

主损失为：

```text
L = 1.0 * policy_cross_entropy
  + 0.35 * distance_loss
  + 0.25 * action_ranking_loss
  + 0.20 * risk_loss
  + 0.10 * symmetry_consistency_loss
```

策略损失只在合法动作上计算；距离损失使用 Huber 加距离分桶交叉熵；排序损失要求教师动作优于其他合法动作；风险损失标记循环、超预算和明显偏离教师路线的动作。

默认使用 5 折交叉验证。每折使用独立随机种子和状态互斥验证集，按验证集的综合分数选择最佳 epoch：

```score = 0.55 * solve_rate
      + 0.20 * first_action_accuracy
      + 0.15 * distance_accuracy
      + 0.10 * (1 - normalized_loop_rate)
```

最终部署模型是五折模型的集成；每折独立前向，输出概率、距离、价值和风险取平均。报告同时保存每折指标、集成指标和按距离桶拆分的指标。

## 5. 纯神经运行时

运行时先对当前状态做一次批量神经前向，然后执行固定预算的 neural beam planner：

- 默认 beam width 为 32，可配置为 64。
- 最大神经规划深度为 96。
- 每个候选只按模型的策略概率、距离预测、动作价值和风险分数排序。
- 不调用 A*、`Board.get_road`、`heuristic_score` 或任何外部搜索器。
- 只使用合法动作过滤，防止越界动作被执行。
- 每个候选路径保存已访问状态；优先淘汰会重复状态的路径。
- 找到目标状态后立即缓存动作序列，实际执行时逐步消费缓存。
- 当前状态偏离缓存计划时重新运行神经 beam。

如果神经 beam 没有找到目标状态，系统不调用 A* 兜底，而是使用当前模型的单步策略选择继续运行，直到达到 30 秒或 100 步上限；该事件计入失败和“beam 未闭合”指标。

## 6. 30 秒验收协议

每次评估都记录从盘面生成到目标状态出现的完整墙钟时间：

- `solve_rate_30s`：30 秒内到达目标的比例。
- `average_wall_time_ms` 和 P95 墙钟时间。
- `average_steps` 和 P95 步数。
- `average_inference_ms` 和 P95 单步推理时间。
- `loop_rate`、`beam_failure_rate`、`illegal_action_rate`。
- 距离 0–20、21–40、41–60、61–80 的分桶结果。
- 完全随机可解盘面和模型自采样失误盘面的独立结果。

验收门槛作为训练报告中的明确结果记录，而不是未经测试的保证。初始目标为：每个距离桶至少 95% 的 30 秒成功率、非法动作率为 0、循环率低于 1%、P95 单步推理时间不超过当前部署节奏的 10%。

## 7. 单文件分享包

训练过程可以在本地保存五折临时 checkpoint，但最终发布物必须是一个自包含文件：

```text
models/第八代数字华容道高速王.pt
```

该文件包含模型版本、模型名称、棋盘和编码配置、动作顺序、归一化参数、训练配置、五个折模型的完整 `state_dict`、每折验证指标以及集成运行时参数。加载器直接从文件内恢复五折模型，不读取同目录下的 `fold-*.pt`，因此别人只拿这一个 `.pt` 文件即可使用：

```bash
uv run python -m render.window --model models/第八代数字华容道高速王.pt
```

五折文件只作为训练中断恢复和调试用的临时文件；最终分享包不保存外部路径引用，也不依赖当前机器的工作目录。checkpoint 写入前必须做一次自包含加载测试，复制到临时空目录后仍能完成模型加载和一次合法决策。

## 8. 训练过程可视化与视频

每次第八代训练都输出结构化指标、静态图和一段 MP4。视频使用固定的测试盘面和固定随机种子，避免训练初期与后期比较时更换题目。视频内容包括：

- 训练指标时间轴：五折平均损失、首动作准确率、分桶解题率和 30 秒成功率。
- 同一组盘面上的训练初期模型与最终集成模型并排棋盘动画。
- 当前步数、预测剩余距离、动作置信度、是否循环和最终是否到达目标。
- 训练初期失败或绕路的代表性片段，以及后期成功片段。

默认输出文件为：

```text
reports/第八代数字华容道高速王-训练过程.mp4
reports/第八代数字华容道高速王-训练指标.png
reports/第八代数字华容道高速王-训练指标.json
```

视频生成不参与模型决策，也不修改 checkpoint。优先使用系统 `ffmpeg` 将固定帧序列编码为 H.264 MP4；若编码器不可用，训练仍完成并保留帧序列、指标 JSON 和静态图，同时在报告中记录视频生成失败原因。
